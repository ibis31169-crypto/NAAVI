# NAAVI

NAAVI — сервер поиска и тестирования туннелей.

Этот репозиторий — **карта источников** для NAAVI. Кода, ключей и паролей здесь нет: исходники NAAVI остаются на сервере.

## Как это работает
* `sources/github.tsv` — список публичных подписок (файлов с серверами) на GitHub.
* NAAVI читает этот файл **каждые 30 минут** и ставит новые подписки в очередь.
* Каждый сервер из подписки NAAVI проверяет сама: 3 успешные живые проверки → «подтверждён» → попадает в BIN.
* Удалить подписку из списка — значит перестать добавлять её снова. Уже найденные серверы NAAVI проверяет как обычно.

Чтобы NAAVI могла читать файл, **репозиторий должен быть публичным**. Пока он закрыт, NAAVI просто пропускает его без ошибок.

## Как добавить источник
Добавьте строку в `sources/github.tsv` (через табуляцию):

```
owner/repo	main	путь/к/файлу.txt
```

Подходят файлы со ссылками `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `tuic://` — простым текстом или в base64.

## Журнал
* `sources/RATING.md` — какие источники реально дают рабочие туннели.
